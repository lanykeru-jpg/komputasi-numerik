Deskripsi: Meminta implementasi metode numerik (Eliminasi Gauss dengan Substitusi Balik) dalam bahasa pemrograman Python beserta panduan tahapan Git/GitHub untuk penyimpanan repository.

2. Prompt: Penentuan Nama File Kode
Isi: "nama file"
Deskripsi: Menanyakan dan menentukan nama file standar untuk kode Python yang dibuat (spltv_gauss.py).

Isi: "Simpan seluruh prompt AI yang Anda gunakan dalam sebuah file .txt dan simpan pada Repository 'Komputasi Numerik' di Github"
Deskripsi: Meminta dokumentasi seluruh riwayat prompt interaksi dalam bentuk file teks (.txt) untuk diunggah ke repository GitHub.
